常见问题FAQ

问得最多的几件事。Questions people ask.

没找到答案？Didn’t find it? 来 GitHub 问我们Ask us on GitHub。.

cc-moss 是什么？What is cc-moss?

一个照看 Claude Code 会话的小工具。它住在菜单栏里，告诉你每个会话是在忙、在等你，还是断了；电脑重启后，点一下就能把断了的会话都接回来，接着原来的对话。A small app that looks after your Claude Code sessions. It lives in your menu bar and shows which sessions are busy, waiting for you, or stopped. After a restart, one click brings the stopped ones back, right where each conversation left off.

怎么安装？How do I install it?

打开「终端」，粘贴 brew install larrykoo711/tap/cc-moss && cc-moss install 回车，然后跟着欢迎页走，一分钟就好。没有 Homebrew 的话，可以在 GitHub 上下载。Open Terminal, paste brew install larrykoo711/tap/cc-moss && cc-moss install and press Return, then follow the welcome. It takes about a minute. No Homebrew? Download it from GitHub.

怎么打开面板？How do I open the panel?

连按两下 Control，或者点菜单栏里的 ∞ 图标。想换成别的快捷键，在设置里改。Double-tap Control, or click the ∞ icon in the menu bar. You can pick a different shortcut in Settings.

电脑重启了，会话怎么找回？My Mac restarted. How do I get my sessions back?

打开面板，点「全部找回」。每个会话都会回到原来的文件夹，接着原来的对话继续。Open the panel and click Bring All Back. Each session reopens in its own folder and picks up the same conversation.

Claude 在等我确认时，我怎么知道？How will I know when Claude needs me?

cc-moss 会提醒你：发一条系统通知，或者让小莫冒个泡。两者只会有一个，不会重复打扰。cc-moss tells you, with a notification or a word from Mo. Only one of the two, never both.

小莫是谁？可以关掉吗？Who is Mo? Can I turn it off?

小莫是住在桌面一角的小伙伴：有会话等你时会冒泡提醒，点它还会跳、会说话。不喜欢的话，在设置里让它安静一点，或者干脆关掉。Mo is a little friend in the corner of your desktop. It speaks up when a session needs you, and hops and talks when you click it. If it’s not for you, make it quieter in Settings, or turn it off.

会上传我的对话吗？Does cc-moss upload my conversations?

不会。会话记录只存在你自己的电脑上。cc-moss 每天最多联网一次，只为检查有没有新版本，不带任何关于你的信息，也可以关掉。No. Your session records stay on your own computer. cc-moss goes online at most once a day, only to check for a new version. It sends nothing about you, and you can turn it off.

需要什么电脑？What do I need?

一台 macOS 14 或更新系统的 Mac，再装好 Claude Code。Linux 上也能用，不过是终端版，没有菜单栏 App。A Mac with macOS 14 or later, and Claude Code. It also runs on Linux, as a terminal tool without the menu bar app.

怎么更新？怎么卸载？How do I update or remove it?

更新：在终端运行 cc-moss update。卸载：运行 cc-moss install --uninstall，它会先问你，再把装过的东西都清理干净。To update, run cc-moss update in Terminal. To remove it, run cc-moss install --uninstall: it asks first, then cleans up everything it added.

收费吗？Is it free?

免费，而且开源（MIT 许可）。Yes. It’s free and open source (MIT).
