背景 / 铁证

Stage 1（v0.1.1）让会话在崩溃、重启后能找回，但一切都要先打开终端敲 t 才看得到。用户要的是一个常驻菜单栏、精心设计的原生面板：图标动画表达动态，会话事件进通知中心；之后再长出桌面宠物、代办确认与语音对话。

#缺口
D1会话状态只有打开终端敲 t 才看得到
D2重启后没有任何东西提醒「有会话断了」
D3去某个会话得先找到一个终端窗口
D4用户原始需求：macOS 原生常驻状态栏 App

根因 / 缺口

App 需要现状
读全部会话与状态✅ ls --json，0.2 秒
按项目分组、worktree 标记⚠️ 选择器里有，JSON 里没有
「刚发生了什么」（事件）❌ 只有快照
「需要你确认」❌ 未注册 Notification 钩子
找回、新建、便条、不再提醒✅ CLI 命令齐全
GUI 进程找到 cc-moss 与 tmux❌ GUI 的 PATH 极简，需 App 补齐

方案核心

 Claude Code ──钩子──> cc-moss hook ──> registry.db（快照 + events 表）
                                           │ 只经 CLI 读写
 cc-moss.app ── ls --json / events --since ┘
   ├─ 面板：搜索、按项目分组、两行卡片、找回横幅
   ├─ 图标动画：在忙流动 / 需要你确认轻跳 / 断了琥珀 / 在等你小圆点
   ├─ 通知中心：按类型开关，点击即在终端打开
   └─ 打开会话：Ghostty / iTerm2 / Terminal 新窗口执行 cc-moss attach

已拍板：Swift + SwiftUI、macOS 14+；App 不碰数据库；事件是一等公民；随 cc-moss 一起发（ad-hoc 签名，不走 cask）；本迭代不拦截确认。
