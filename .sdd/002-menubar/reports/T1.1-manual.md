- 用户打开面板截图（2026-10-16）：真实会话按项目分组显示，摘要条计数（在忙 2 / 在等你 11 / 已中断 0）、「不在 tmux 里」标记、最后一句话都正确 ✅

- 用户反馈：浅色主题被壁纸染成蓝灰、对比度低 → 已改为 Raycast 式近不透明浅色底、浮动动作胶囊、分键键帽（A17），重装后待用户复看
- 用户反馈：每行一个黄色「在等你」标签让人眼花 → 标签只留给需要你动手的状态（已中断；以后加「需要你确认」），「在等你」只保留左侧小圆点并调柔琥珀色
- 用户反馈：摘要条的三块磁贴「毫无设计感」→ 改为带滑块动画的分段控件（全部 / 在忙 / 在等你 / 已中断，计数在段内，选中段是白色浮起滑块、弹簧动画滑动；Tab / ⇧Tab 切换）
- 用户反馈：切换有拖影、闪烁、没有滑动 → 原实现每段各画一个背景靠 matchedGeometryEffect 匹配，切换时是两块背景交叉淡入淡出。改为始终只有一个滑块、只改它的水平位置；文字不再变粗（避免宽度跳动）；动画只作用在滑块上。用 `--preview --cycle` 预览窗口连拍 40 帧核实：约 0.3 秒内滑块逐帧平移，没有残影
- 用户反馈：worktree 没标出来 → 开发版 App 调的是 Homebrew 装的 0.1.1，那时的 `ls --json` 还没有 `worktree` 字段。加了 `cliPath` 偏好（T2.4 设置页的「cc-moss 路径」），开发时指向本分支构建的 cc-moss；正式发布时 App 与 CLI 同版本，不会再错配

## 图标语言（A21）

- 用户反馈：整个 App 几乎没有图标，全是文字 → 建立统一图标词汇；状态图块（Raycast 式带底色的圆角方块）、项目文件夹、便条 / 最后一句的区分图标、⌘K 菜单与主动作图标
- 用户补充：按 Apple 设计哲学「适当用图标替换文字」→ 筛选未选中段只留图标 + 数字、选中段展开名称；去掉「已中断」文字标签、worktree 与「不在 tmux」改为带提示的图标、去掉时间前的时钟
- 动画复核（`--preview --cycle` 连拍）：第一版标签淡出时压到相邻数字、图标与文字交错；改为整排内容直接到位、只有滑块移动和伸缩，逐帧无重叠

## 动作栏反馈与设置窗口

- 用户反馈：底部动作栏纯静态，没有悬停与点击反馈；希望 logo 悬停时动起来、点击进入设置
- 处理：胶囊里的按钮悬停高亮、按下微缩；键盘触发 ↵ / ⌘K 时对应键帽亮一下；左下 logo 悬停时缺口沿环流动并转为品牌色，点击（或 ⌘,、⌘K 菜单里的「设置…」）打开设置窗口
- 设置窗口提前搭好 T2.4 的骨架（A20 Raycast 式：工具栏图标标签页、两栏表单、即时生效），本轮只放已能工作的两页：
  - 通用：cc-moss 命令路径（可选择文件，留空自动找），显示正在使用的版本（`T1.1/settings-general.png`）
  - 关于：流动的 Continuum 标志、版本、标语、检查更新（调 `cc-moss update --check`，原样显示它的话）、GitHub（`T1.1/settings-about.png`）
- 真机：经 ⌘, 打开设置窗口、切换两个标签页、检查更新均正常
- 用户反馈：设置窗口还是 macOS 默认的 Settings 样式 → 改为自绘窗口：隐藏标题栏、与面板同一层磨砂底色、居中的图标磁贴标签页（选中块滑动、图标转品牌色）、填充式输入框、带悬停与按下反馈的圆角按钮、App 图标式的流动标志；`--render out.png --settings general|about` 离屏渲染（截图已替换）
- 菜单栏 App 打开的窗口会落在其他 App 后面：等 SwiftUI 真正建好窗口后再激活并置前（重试至多 1 秒）。自动化脚本里按键或点击会让面板先失焦，无法可靠复现「点 logo」这条路径，留待真机确认
- 用户对照 Raycast 标注三处差距（内容区左上的前进后退、大号搜索框、侧栏的身份行与条目尺寸）→ 改回自绘侧栏：macOS 26 上用系统 Liquid Glass（`glassEffect`），更早的系统退回毛玻璃；红黄绿按钮收进侧栏；大号胶囊搜索框；36pt 条目、14pt 字；玻璃前进后退胶囊（记录访问过的页面）；行文字 14pt、说明 12pt；开关用系统蓝
- 用户反馈悬停问题：「复制命令」的悬停底块是小圆角矩形，顶到外层胶囊的弧边 → 改为与外层同心的胶囊形底块
