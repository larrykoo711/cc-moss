## 目标

电脑重启或 App 崩溃后再打开，cc-moss 主动说一句「有 N 个会话断了」，点开就能全部找回；任何时候按一个全局快捷键就能唤出面板；界面语言可以在设置里选，并且和 CLI 共用一处配置。

## Scope（YAGNI）

**In**
- 开机提醒：App 把「上次看到时在运行的会话」记在偏好设置里（会话列表变化时更新）。启动后第一次拿到快照时，比对出「上次在运行、现在断了」的会话：
  - 没有记录（首次安装）→ 不提醒，只开始记录
  - 1 个 → 走 T2.3 的单条「断了」提醒
  - 多个 → 一条汇总：「有 N 个会话断了」，正文「电脑重启了？对话都还在，点开就能全部找回。」；点通知 / 小莫消息框的主动作 → 面板筛到断了的会话（横幅上「全部找回」一键可达）
  - 仍然遵守 T2.3：提醒方式、「会话断了」类型开关、勿扰、面板开着不提醒、不会两边都响
- 全局快捷键：Carbon `RegisterEventHotKey`（不需要辅助功能权限）。默认 ⌃⌥M；设置 › 通用 ›「唤出面板」录制器：点一下进入录制，按下组合即保存，Esc 取消，删除键清除；组合必须含 ⌘/⌃/⌥ 之一；注册失败（被占用）就地提示并保留旧值；按下快捷键 = 状态栏图标单击（面板开着则收起）
- 界面语言：设置 › 通用 ›「界面语言」：跟随系统 / 中文 / English。写入经新 CLI 命令 `cc-moss config set ui.language auto|zh|en`（只认白名单键，原子写，保留文件里的注释与其他内容）；`cc-moss config get ui.language [--json]` 读取。App 启动时读取一次，切换后立即重绘所有窗口（面板、设置、小莫气泡）；`t` 与 CLI 下次运行生效

**Out**
- 通用的 `config` 编辑器（只开放 `ui.language`，其他键以后按需加）
- 开机提醒里直接「全部找回」按钮（通知只带一个主动作，找回在面板里一键完成，避免点通知就批量启动进程）
