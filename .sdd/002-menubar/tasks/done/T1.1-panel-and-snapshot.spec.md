## 目标

菜单栏出现 cc-moss 图标，点开是一个精心设计的面板：顶部搜索框，会话按项目分组，每个会话两行（状态点、名字、
状态、多久之前 / 便条或最后一句话），数据随钩子写入实时刷新。找不到 cc-moss、CLI 出错、登记表来自更新版本时，
面板给出友好的引导而不是空白。

## Scope（YAGNI）

**In**
- CLI：`ls --json` 顶层加 `state_dir`（App 据此监听目录，不自己重算路径），每个会话加 `worktree`（`{root, repo}` 或 `null`）。schema 仍为 1，只增不改
- `apps/macos/` Swift Package（swift-tools 5.10，`platforms: [.macOS(.v14)]`）：
  - `MossKit`（库）：
    - `Locator`：按 DESIGN §5 的顺序找 `cc-moss`，可注入「文件可执行」判断
    - `Runner`：执行命令，补齐 PATH（cc-moss 所在目录 + `/opt/homebrew/bin` + `/usr/local/bin` + 系统目录），10 秒超时；协议可注入假实现
    - `Snapshot`：解码 `ls --json`；`schema > 1` 报「需要升级 App」；可选字段缺失容忍
    - `SessionState`：在忙 / 在等你 / 已中断 / 已关闭，口径与选择器 `State::of` 一致（running+busy、running+!busy、interrupted）
    - `Grouping`：按 `cwd` 分组，组与组内都按最近活动倒序（对齐 `pick/app.rs` `group`）；组名取目录名，重名时取 `~` 缩写的路径（对齐 `pick/ui.rs` `project_labels`）；已关闭的会话不显示
    - `Filter`：不区分大小写的子串匹配，范围是名字、项目名、便条、最后一句话
    - `L`：中英文案函数，跟随系统首选语言，`CC_MOSS_LANG` 可覆盖（与 CLI 的 `tr!` 一致）；相对时间（刚刚 / N 分钟前 / N 小时前 / 昨天 / M 月 D 日）
  - `CCMoss`（可执行，SwiftUI `MenuBarExtra` `.window` 样式）：
    - 静态 Continuum 图标（SwiftUI `Path` 绘制的模板图，T2.2 在此基础上做动画）
    - 面板约 380×540：搜索框（打开即聚焦）、分组列表、两行会话行、底栏（版本、刷新状态、退出）
    - 键盘：打字即搜索，↑↓ 选择，Esc 关闭
    - 空状态、找不到 cc-moss（给一条 `brew install` 命令可复制）、CLI 出错（原样显示 stderr 首行）、需要升级四种引导卡
    - 不在 tmux 里的会话行尾标注「不在 tmux 里」
  - `Watcher`：对 `state_dir` 开 FSEvents（文件级事件、延迟 1 秒合并），变化即刷新；另 60 秒兜底；打开面板时立即刷新；同一时刻最多一个 `ls` 在跑
  - `scripts/bundle.sh`：组装 `cc-moss.app`（`Info.plist`：Bundle ID、`LSUIElement`、版本号取 workspace `Cargo.toml`）并 ad-hoc 签名；`scripts/dev-install.sh`：构建 → 装进 `~/Applications` → 启动（探针 Q6：通知只在应用程序目录里可用）
- CI：新增 `macos-app` 任务，在 `apps/macos/` 跑 `swift build` 与 `swift test`

**Out**
- 打开会话（T1.2）、找回（T1.3）、图标动画（T2.2）、通知（T2.3）、开机自启与设置窗口（T2.4）、新建/便条（T2.5）

## 风险与回退

- FSEvents 在某些文件系统上不来事件：60 秒兜底保底；面板打开时总会刷新
- `ls` 每次都会跑一次对账（含 `claude agents`），频繁变化时的耗电：FSEvents 1 秒合并 + 同时最多一个 `ls`
- 回退：App 是独立产物，删掉不影响 CLI；CLI 新字段只增不改
