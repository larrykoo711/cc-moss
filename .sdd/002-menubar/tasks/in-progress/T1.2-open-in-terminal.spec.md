## 目标

在面板里点会话（或回车）就在用户选的终端里开一个新窗口进入它。设置里有「终端」一项：系统自带的终端为默认，
Ghostty 标为推荐（没装时给推荐与下载入口），另支持 iTerm2、WezTerm、Kitty、Alacritty。不支持的终端与失败情况都有「复制命令」兜底。

## Scope（YAGNI）

**In**
- MossKit `Terminal`：六种终端的 Bundle ID、显示名、是否推荐；`TerminalCatalog` 用可注入的「按 Bundle ID 找 App 路径 / 读版本」探测已安装的
- MossKit `LaunchPlan`：给定终端、cc-moss 绝对路径、会话 handle，生成要执行的东西：
  - Terminal：AppleScript `do script` + `activate`
  - Ghostty ≥ 1.3：AppleScript `new surface configuration`（`command`）+ `new window with configuration`；< 1.3：`open -na <app> --args -e <shell> -lc <cmd>`
  - iTerm2：AppleScript `create window with default profile command`
  - WezTerm：`<app>/Contents/MacOS/wezterm start -- <shell> -lc <cmd>`
  - Kitty、Alacritty：`open -na <app> --args … <shell> -lc <cmd>`
  - 命令一律是 `'<cc-moss 绝对路径>' attach '<handle>'`，shell 单引号转义；嵌进 AppleScript 字符串时再转义 `\` 与 `"`；`<shell>` 取用户登录 shell（`$SHELL`，缺省 `/bin/zsh`）
- App：执行计划（`NSAppleScript` / `Process`）；首次会触发系统「自动化」授权，拒绝时（-1743）给出引导：一键打开「系统设置 › 隐私与安全性 › 自动化」，并提供复制命令
- `bundle.sh` 的 Info.plist 加 `NSAppleEventsUsageDescription`（中英）
- 面板：主动作改为「打开 ↵」（显示所选终端的 App 图标）；「复制命令」移到 ⌘K；不在 tmux 的会话主动作是复制命令并在悬停提示里说明原因；已中断的会话主动作暂为「复制找回命令」（T1.3 改成一键找回）；打开后面板收起
- 设置 › 通用：新增「终端」分组：选择器列出已安装的受支持终端（带 App 图标），默认终端；Ghostty 带「推荐」标记；没装 Ghostty 时一行推荐与下载按钮（ghostty.org）

**Out**
- 切到已经打开该会话的终端窗口（后续）；Warp、VS Code 内置终端（无稳定接口，只给复制命令）
