## 目标

打开宠物后，桌面上出现小莫：透明、无边框、置顶、不抢焦点的小窗；按会话状态做六个动作（待机、在忙、需要你、断了、开心、睡觉）；
可拖动、贴边、记住每块屏幕上的位置；单击打开菜单栏面板；右键菜单；设置里可开关、选大小。空闲开销达到设计预算。

## Scope（YAGNI）

**In**
- MossKit `PetGeometry`：Continuum 参数 → 路径（各动作同点数，便于插值）；六个动作的参数表（DESIGN-pet §4）
- MossKit `PetPose`：由快照与环境算此刻动作，优先级 睡觉 > 需要你 > 断了 > 在忙 > 待机；「开心」为一次性演出（`restored` 事件触发，播完回到算出的动作）；勿扰在本任务只有手动开关（右键菜单），专注模式与离开检测属 T3.3
- MossKit `PetPlacement`：按屏幕存位置（相对可见区域）、拖动松手 24pt 内贴边、屏幕变化时夹回可见区域、屏幕不在时回主屏右下角 Dock 之上 24pt
- CCMoss `PetWindow`：`NSPanel` 按 §8 配置；内容视图 `hitTest` 只认身体形状，透明处点击穿透到下层窗口（先做探针：若不可靠，按鼠标位置切换 `ignoresMouseEvents`，结论写进 notes）
- CCMoss `PetLayer`：`CAShapeLayer` 图层树（身体、眼、天线、灯、阴影），动作切换用 `CABasicAnimation`/`CASpringAnimation`；循环（呼吸、缺口流动）为无限重复的图层动画；循环上限 30fps（`preferredFrameRateRange`）；窗口被遮住 / 屏幕休眠 / 2 分钟无事时移除循环动画；减少动态效果时只做 0.2 秒淡入淡出、跳与招手改为灯闪一次；悬停时眼睛看向鼠标（彩蛋，§13-11）；连点三下开心一下
- 交互：单击 = `PanelController.show()`（T2.2 已提供）；右键菜单：打开面板 / 勿扰一小时 / 今天勿扰 / 收到边上 / 宠物设置… / 隐藏宠物（静音、演示模式属 T3.3–T3.4，菜单里先不出现）
- 设置 › 通用新增「桌面宠物」分组：开关（默认关；首次启动引导里再问，见 T4.2）、大小（小 48 / 中 64 / 大 88，Raycast 式分段，同面板滑块风格）
- 共用 `AppModel` 与 Watcher，不另起刷新
- `--pet-sheets` 增加真实图层的离屏出图（各动作关键帧），与 T3.1 原型逐项比对

**Out**
- 气泡与事件导演（T3.3）、语音（T3.4）、专注模式 / 全屏 / 离开 / 演示模式探测（T3.3）

## 风险与回退

- 图层动画在 WindowServer 里也有成本（T2.2 的教训）：普通窗口不像菜单栏那样按屏复制，但仍要实测；超预算就降循环帧率、缩短循环、2 分钟无事即静止
- 点击穿透不可靠：按鼠标位置切换 `ignoresMouseEvents`
- 回退：设置里关掉宠物即完全移除窗口与图层
