## 目标

断了的会话在面板里一键找回：顶部横幅「有 N 个会话断了 · 全部找回」，单行「找回」，找回后可直接在终端打开。
很久以前断开的会话（默认 7 天前）折叠成「更早断开的 N 个」，不与刚断开的混在一起；找不回的（空会话、目录没了）说明原因。

## Scope（YAGNI）

**In**
- CLI：`cc-moss restore --yes --json [name…]` 输出每个会话的结果 `{schema:1, results:[{id,name,ok,reason?}]}`（reason 用稳定的代码：`empty`、`missing_dir`、`exited_at_once`、`tmux_failed`、`already_running`），文字输出不变
- MossKit `RestoreGroups`：把已中断会话分成「最近」与「更早」（按 `last_active_at`，阈值 7 天，可注入时钟）
- MossKit `RestoreFlow`：命令拼装、JSON 解码、进行中状态（同一会话或全部进行中时再点无效）、失败原样带出 CLI 的话
- 面板：
  - 有最近断开的会话时，列表顶部一条横幅：图标 + 「有 N 个会话断了」+ 主按钮「全部找回」；找回中显示进度，完成后变成「找回了 N 个」并在 3 秒后收起
  - 已中断行：悬停按钮与主动作从「复制找回命令」改为「找回」；找回成功后该行变回在等你 / 在忙，并提供「打开」
  - 「更早断开的 N 个」折叠组：默认收起，展开后可逐个找回或「都不再提醒」（`cc-moss close`，需确认）
  - 找不回的行显示原因（空会话：「这个会话还没说过话，没什么可找回的」）与「不再提醒」
- 筛选栏「已中断」计数只算最近的；折叠组单独显示数量

**Out**
- 开机后自动提醒（T2.4）；自动找回（R8：永远由用户触发）
