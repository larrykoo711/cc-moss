## 目标

提醒交给小莫时（T2.3 路由 → T3.3 导演），小莫按设置出声：**关**（默认）、**提示音**（系统自带的一声）、**说话**（本机合成，只读气泡标题）。说什么跟互动模式走，勿扰时不出声，30 秒最多一句，新句子来时旧句子没说完就丢掉。设置里能挑本机已装的声音、试听，并一键去系统设置下载更好的声音。

## Scope（YAGNI）

**In**
- MossKit `VoiceMode`：off / chime / speak，存 `petVoice`，默认 off
- MossKit `VoicePolicy`（纯逻辑）：输入提醒类型、互动模式、勿扰、声音设置、当前时刻 → `.nothing` / `.chime` / `.speak(text)`
  - 互动模式 → 哪些类型出声：安静 = 只有需要你；日常 = 需要你 + 断了；积极 = 再加找回、做完
  - 30 秒节流（提示音与说话共用）；勿扰一律不出声；设置为关一律不出声
  - 文本 = 气泡标题（`PetMessage.text(names:).title`），只含会话名，不读正文、不读会话内容；随界面语言
- MossKit `VoicePicker`（纯逻辑）：从（标识、语言、质量、名字、是否新奇声音）列表里
  - 列出当前界面语言的已装声音（排除新奇声音），高级 > 增强 > 默认；中文先普通话（zh-CN / zh-TW），再粤语
  - 选声：存的标识还装着就用它，否则选该语言最好的；一个都没有返回 nil（交给系统按语言挑）
- MossKit `VoiceAnnouncer`：把策略、选声和可注入的输出（协议 `VoiceOutput`）接起来，测试里用假输出，测试从不真的出声
- CCMoss `Speaker`：`AVSpeechSynthesizer` 包装；新句子前 `stopSpeaking(at: .immediate)`；语速、音量取系统默认；提示音用 `NSSound(named: "Tink")`，不打包音频
- 接线：`PetController.take(_:)` 里导演决定示意（返回 true）时才交给 announcer；只有路由给小莫的提醒才会到这里（通知中心自己会响）
- 设置 › 小莫：「声音」卡片，小莫关着时不显示
  - 出声方式 SlidingPicker：关 / 提示音 / 说话（默认关），一行说明
  - 说话时：声音 Dropdown（「自动」+ 当前界面语言的已装声音，带「高级 / 增强」标签）+「试听」SoftButton；「下载更好的声音」链接 → 系统设置 › 辅助功能 › 朗读内容
  - 提示音时：「试听」
- `SettingsView.Tab.keywords` 的小莫一项加声音相关的中英搜索词（`SettingsView.swift` 只改这一处）
- 截图：`--render ... --settings mo --pet-on`，只在渲染进程的注册域（不落盘）里打开小莫，不碰 App 的真实偏好设置

**Out**
- 音量、语速滑杆（跟随系统；PLAN 里写的「可调音量」以系统音量为准，YAGNI）
- 首次打开小莫时问「要不要让小莫开口说话？」（§6.4）——放 T4.2 首次启动引导
- 开会（麦克风 / 摄像头被占用）、不在电脑前时静音（§6.2）——另记开放问题
- 系统专注模式（T3.3 已定：只用小莫自己的勿扰）
- 列出「可下载但未下载」的声音（没有 API，§2.4）
