## 目标

第一次打开 App 时，一个精致的欢迎窗口用几步讲清楚 cc-moss 能做什么，并当场把该做的事做完：装好终端工具与钩子、开机自动打开、通知授权、默认终端、要不要小莫与它开口。走完就能用，不必再回终端读文档。

## Scope（YAGNI）

**In**
- 窗口：无标题栏、面板同款毛玻璃与圆角，约 640×460；顶部大图（小莫或 App 图标）、标题、一句副标题、本步内容；底部左侧进度点、右侧「上一步 / 继续」（最后一步「开始使用」），右上「跳过」。步骤切换左右滑动；减弱动态效果时改为淡入淡出
- 六步：
  1. 欢迎：小莫打招呼 + slogan「文明会延续，对话也是。」+ 三句话讲清能做什么（看着会话、断了能找回、在哪儿都能唤出）
  2. 终端工具：列出 钩子 / tmux / starship / shell 区块 各自状态（已就绪 / 需要安装），数据来自新的 `cc-moss install --dry-run --json`；一个「一键装好」按钮执行 `cc-moss install --yes`（App 已在运行，跳过 `app` 部分），完成后刷新状态；也可「在终端里看细节」复制 `cc-moss install --dry-run`
  3. 开机与通知：「开机自动打开」开关（A8 默认开，此处即那一次询问）；通知「允许通知」按钮触发系统授权，显示当前状态
  4. 终端：复用设置里的终端选择器，Ghostty 带「推荐」
  5. 小莫：要不要小莫（开 / 关），要不要它开口（关 / 提示音 / 说话，默认关；T3.4 裁决 ③）
  6. 完成：⌃⌥M 唤出面板的提示（显示当前快捷键）+「打开面板」
- 已满足的步骤自动打勾（钩子都在、通知已允许）；可跳过任意步骤；整个引导可跳过
- 只出现一次：首次启动；之后可在 设置 › 关于「再看一遍欢迎引导」打开
- CLI：`cc-moss install --dry-run --json` 输出 `{"schema":1,"parts":[{"part":"hooks","state":"ready"|"changes"|"skipped"|"unsupported","summary":"…"}…]}`，覆盖每一部分

**Out**
- 账号、云同步（cc-moss 没有账号）
- 安装 Homebrew / Claude Code 本身（只检测并给出链接）
