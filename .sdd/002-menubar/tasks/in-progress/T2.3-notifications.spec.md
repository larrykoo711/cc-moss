## 目标

会话发生值得告诉你的事时，只在一个地方提醒你一次：小莫在桌面上可见时由它负责（T3.3 实现它的表达），否则发到系统通知中心；
点通知 = 打开那个会话（或找回）。通知按类型可开关，同一会话短时间内的重复事件合并。

## Scope（YAGNI）

**In**
- MossKit `AlertRouter`（纯逻辑，可单测，T3.3 复用）：输入事件 + 环境（提醒方式设置、小莫是否可见、面板是否打开、勿扰）→ 出口 `.notification` / `.pet` / `.none`；已路由过的事件 id 不再路由（不补发）；面板打开时面板里看得到的不提醒
- 事件来源：`events --json --since`（App 首次启动从当前 `last_seq` 开始，不回放旧事件，见 T2.1 澄清）；随快照刷新拉增量
- 类型与默认（A9）：需要你确认 开、会话断了 开、这一轮做完了 关、找回完成 开；合并窗口 30 秒（同会话同类型）
- `UNUserNotificationCenter`：首次需要时请求授权；被拒时设置页给出引导（打开系统设置 › 通知）；通知带动作「打开」/「找回」，点击正文 = 主动作
- 设置 › 新增侧栏「通知」页：提醒方式（自动 / 只用通知中心 / 只用小莫）+ 四个类型开关 + 授权状态；用 SlidingPicker 与 CardRow
- 小莫这一侧：本任务只向 `PetController` 报告「这件事归你」（T3.3 才做气泡）；小莫没开时一律走通知中心

**Out**
- 小莫的气泡与互动模式（T3.3）；开机提醒（T2.4）
