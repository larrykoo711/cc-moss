## 目标

T2.3 的提醒路由把事情交给小莫后，小莫按用户选的互动模式表达：**安静**只用表情动作，点它才出消息框；**日常（默认）**表情动作之外，身边浮起半透明的口头禅小气泡，悬停才展开完整消息框；**积极**直接弹出消息框。
消息框里的主动作与通知中心一致（打开会话 / 找回）。

## Scope（YAGNI）

**In**
- MossKit `PetDirector`（纯逻辑）：输入「归你」的提醒 + 模式 + 悬停 / 点击 + 时钟 → 当前要显示的东西（无 / 口头禅小气泡 / 完整消息框）、口头禅文案、何时收起；同类 1.5 秒合并成一个、一次只一个气泡、同一件事 60 秒内不重复、勿扰时只保留表情（T3.2 的动作）
- 口头禅：中英各一组（「嗯？」「…」「有件事～」「回头看一眼？」/ "Hm?" "…" "Got a sec?" "One thing…"），随机轮换，几秒后淡出
- CCMoss `PetBubble`：
  - 小气泡：半透明、圆角胶囊、贴着小莫上方，淡入淡出
  - 消息框：DESIGN-pet §6.3 的四段结构（标题 / 正文 / 详情区（本任务不用）/ 动作区），主动作 + 「稍后」；鼠标移开约 1.5 秒收起，回到框上不收
  - 用 `.tip()`、`.handCursor()`、SoftButton 等现有组件；中英文
- 窗口：气泡出现时宠物窗口临时扩大，透明区域照旧穿透
- 设置 › 通用 ›「桌面宠物」卡片加「互动方式」：安静 / 日常 / 积极（SlidingPicker，默认日常）
- 主动作接线：打开 = T1.2 的 Opener；找回 = 若 T1.3 已合入则一键找回，否则打开面板并选中（与 T2.3 `AlertCenter.perform` 同一入口）

**Out**
- 语音播报（T3.4）；代办确认的「同意 / 拒绝」（004）

## Notes / 开放问题 / 澄清日志

- 2026-10-16 实施决定（T3.3 agent）：
  - 「宠物窗口临时扩大」实现为挂在宠物窗口上的子窗口（`PetBubbles`）：随小莫拖动、一起隐藏，窗口只在气泡出现时存在，大小 = 气泡 + 四周 28 pt 阴影余量，透明处照旧穿透；不改 T3.2 的定位、贴边、拖动逻辑。效果与「临时扩大」等价
  - 60 秒不重复对所有类型生效（含「需要你」，以本 spec 为准，DESIGN-pet §5 的例外不采用）；重复的一件事不再示意，但仍由小莫拿着，悬停或点击照样能展开
  - 优先级：需要你 > 断了 > 找回 > 做完；低的被丢弃（面板与图标照常显示）
  - 积极模式的弹框自动收起时长沿用 §6.3：需要你常驻到处理，断了 20 秒，找回 5 秒，做完 6 秒；鼠标来过再离开则 1.5 秒收起
  - 小莫拿着的消息：需要你 / 断了直到处理或不再成立（快照里不再需要你 / 不再断了，刚到 5 秒内的不判），找回 30 秒、做完 60 秒后作废
  - 点小莫：拿着消息且框没开 → 开框；否则照旧打开面板（§7）
  - 多个会话合并时主按钮为「看看」，打开面板并选中第一个；单个会话走 `AlertCenter.perform`（与通知同一入口）
  - 示意动作：`take` 新示意时闪一下天线灯；姿态（招手、睁大眼）仍由快照驱动（T3.2）
- 气泡位置的纯逻辑 `MossKit/BubblePlacement`（默认左上、左边放不下翻到右边、上面放不下放到下面、夹在可见区域内），有单测
