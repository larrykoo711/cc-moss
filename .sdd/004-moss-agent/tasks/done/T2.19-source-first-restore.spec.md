## 合同
- Known Unset/Explicit保持语义并直接Recorded找回；UI展示可验证的来源路径，Unknown历史hint不伪装resolved path。默认显示路径由目标启动HOME解析，不采用Moss覆盖环境。
- 显式目录缺失/非目录/不可读分别typed拒绝；settings.json不存在合法，存在但不可读或非合法JSON对象才标损坏，不输出内容/解析片段、不读凭据。默认目录未创建不误判损坏，HOME需可用。MCP连接错误不是路径损坏。
- source plan最小kind/status/display_path/revision；revision仅安全来源/slot/session与本地元数据，不hash内容或凭据。列表同来源健康读取单次缓存且不阻塞所有运行会话；执行必须重新检查，不能信UI旧ready。
- Unknown仍需一次明确使用默认或所选目录，不自动修改剩余历史记录。用户只需点说明清楚的主按钮，不再先选radio再确认。已知来源不强迫再选。
- 旧Unknown guard保持兼容；替换坏Known来源需expected-source-revision前提绑定用户看到的源状态，变化后config_source_changed拒绝；不能删除guard让旧确认覆盖新来源。取消/token/换代/目录回调守卫保持。
- 目录读取/健康检查早于claim与launch；目录晚于预检改变的FS竞态无法完全消除，真实启动失败准确报告，不自动更换/重试。不预写Snapshot，不复制配置，正常SessionStart记新来源。

## 独立设计复核澄清

JSON健康检查仅验证语法与顶层对象，可流式IgnoredAny跳过值，不提取/保留/日志输出字段值或解析片段；合法对象的provider字段形状不是通用JSON损坏。revision绑定原Recorded语义、slot/session与原源健康元数据，验证原源后才检查候选替代目录，不能对新目录算revision冒充旧授权。旧unknown前提与revision若组合必须同时满足，或明确互斥；不得OR放行。保留planned.provider_started原值CAS，来源变化不替换planned后重试。默认显示路径与执行使用相同明确目标HOME，缺失不借Moss环境猜测；单次列表缓存键含完整来源语义和HOME。实际尝试目录读取区分权限，不仅依赖exists或mode位。

## 接口落点裁决

本轮采用ls会话JSON的可选restore_source，仅interrupted条目解析健康、相同来源按单次调用缓存；不另加source-plan命令。Unknown的display_path保持null；可选default_path来自与实际恢复同一目标HOME，只表示当前默认提案，绝不表示已确认原来源。缺可靠HOME不猜路径。backend/UI明确目录display与默认全局JSON路径的标签区分，旧CLI缺字段兼容显示未确认，不由App独立读取HOME拼接。上述字段为安全路径/元数据，不输出配置内容或凭据。

## HOME与字段写权裁决

default_path确定为目标HOME/.claude的默认配置目录，不标global MCP JSON。restore专用环境显式固定同plan规则验证的CLI HOME（绝对/存在/可读），避免继承tmux旧HOME；env -u选项在赋值之前。restart/adopt不扩这一行为。Moss隔离HOME不得冒充宿主默认源，无法取得明确宿主上下文就拒绝，不猜。测试必须污染tmux HOME并验证显示与实际启动一致。Swift Snapshot仅新增可选restore_source兼容解码，新字段参与既有完整Session等价比较，不改公开全局schema。

## 健康检查预算裁决

列表所有来源共享200ms绝对deadline，restore执行独立2s；每Planner最多64唯一probe，失败计入，缓存命中不计。所有可能慢的metadata/read_dir/open/read/JSON解析/文件stamp及HOME健康均在worker，不在调用线程同步执行。单Planner惰性一个worker，提交try_send，响应按剩余deadline等待；首次超时即exhausted，不继续投递/重建，不join。跨Planner还需进程级活跃worker硬上限，非阻塞许可由worker持有到真实退出，不能超时即释放许可导致批量restore无限积累线程。

settings大小上限1MiB，metadata预拒绝并限额读取limit+1防读取中增长，超限/超时/容量耗尽统一config_source_unavailable、status blocked，不是invalid_settings，不据此自动换源。超时不得合成ready或复用未经验证HOME/default_path。所有来源健康失败均在claim/launch前拒绝。测试用可控阻塞probe验证deadline/drop/线程界限，不依赖真实慢磁盘，不声称文件系统TOCTOU完全消失。
