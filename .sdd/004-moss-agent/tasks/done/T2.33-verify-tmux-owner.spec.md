# T2.33-verify-tmux-owner — Verify live process ownership before marking or labeling a tmux session

- Source: User report 2026-11-24 — after a tmux server restart, session ids start again from `$0`. Stale registry rows whose processes had died without `SessionEnd` still had `status = 'running'` in SQLite and pointed at `$0`, `$5`, `$14`, `$20`. `reconcile` stamped `@managed-by cc-moss` and old `@cc-moss-name` titles onto newly created unrelated sessions (or onto newer live Claude sessions that reused those ids).
- Evidence: `crates/cc-moss/src/reconcile.rs` (`label_tmux`, `mark_tmux`) checked only `slot.status == Status::Running` and `is_tmux_primary` (SQL `status = 'running'`), without verifying `slot.effective_status(proc::is_alive) == Status::Running` or that `slot.pid` actually lives in that tmux session's panes.
- arch_level: no
- depends_on: [T2.32]
- verify_layers: [unit, integration]
- risk: logic
- mutations:
  - point: reconcile skips pane ownership check  red: `reused_session_ids_after_server_restart_are_not_marked_and_stale_marks_clear`
  - point: reconcile does not unset stale `@managed-by cc-moss` / `@cc-moss-name`  red: `reused_session_ids_after_server_restart_are_not_marked_and_stale_marks_clear`
- ui: no

## Goal

Only a slot whose Claude process is alive and verified inside a tmux session's pane tree may own that tmux session's `@managed-by` and `@cc-moss-name` options. Stale cc-moss marks on sessions with no live cc-moss Claude inside them are cleared automatically without touching other tools' `@managed-by` values.

## Scope (YAGNI)

**In**
- `moss-core::tmux`: `session_marks()`, `panes_checked()`, `unmark_managed()`, `unset_display_name()` (all session-level, never `-g`).
- `cc-moss::reconcile`: unify `label_tmux` and `mark_tmux` into `sync_tmux_marks`, verifying both process liveness and pane-tree membership (`pane_pid == pid` fast path, lazy single `proc::parents()` fallback); clear stale `@managed-by cc-moss` and `@cc-moss-name` when no verified live cc-moss Claude runs in the session; never clear another tool's `@managed-by`; skip cleanup if `list-panes` fails; gate transcript-rename tmux sync on live pane ownership.
- `cc-moss::cmd::hook::sync_tmux_name_of`: ignore dead slots when deciding the primary owner of a tmux session so an older dead row cannot block a live session that reused `$N`.
- Unit tests in `tmux_runner.rs` and an e2e server-restart / reused-id test in `new_e2e.rs`.

**Out**
- Touching Moss's server.
- Modifying another tool's `@managed-by` option.
