## 目标

cc-moss 管理的每个 tmux 会话都带会话级选项 `@managed-by cc-moss`，别的工具（如 `ta`）据此只进入、不改名、不关闭。升级后已在运行的会话不用重启，reconcile 会补上。

## Scope（YAGNI）

**In**
- moss-core：常量 `MANAGED_OPTION = "@managed-by"`、`MANAGER = "cc-moss"`；`Tmux::mark_managed(session_id)`（会话级 `set-option`，不碰全局）；`Tmux::managers()`（一次 `list-sessions` 读全部会话的该选项，复用读显示名的写法）。
- 新建（`cmd/new.rs` 设显示名处）与恢复（`cmd/restore.rs` 设显示名处）时打标记。
- reconcile 给运行中、本 slot 为该 tmux 会话主人、还没有标记的会话补上（每个 server 一次读，只写缺的）；Moss 自己的 server 照旧不碰。
- guide 中英各一句说明这个选项。

**Out**
- 读别的工具的标记、改 cc-moss 选择器行为（cc-moss 本来就只管自己登记的会话）。
- 会话结束时清标记（会话没了选项也没了）。
