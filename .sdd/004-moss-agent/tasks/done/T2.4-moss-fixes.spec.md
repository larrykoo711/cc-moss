## 目标

点一下「体检」或「整理会话」，Moss 就把能修的直接修好，再发一段简短的**体检简报**：修了什么、还有什么要你定。会丢东西、会花额度的事，在简报下面弹出选项问你，你点了它再做。每天也自动体检一次，和手动点的完全一样。

## 前置

## 行为口径（待确认）

| 发现的问题 | Moss 怎么办 | 要不要问你 |
|---|---|---|
| cc-moss 的钩子或别名坏了、没装全 | 直接修（等于 `cc-moss setup` + `doctor --fix`） | 不问 |
| 会话名和 tmux 名对不上 | 直接对齐 | 不问 |
| 没名字的会话（只显示一串字母数字） | 按它所在的文件夹起个名字（`ofoxai`、`ofoxai-2`）；会话正在干活时不动，等它闲下来 | 不问 |
| 断了、文件夹也已经没了的会话 | 不再提示恢复（反正恢复不了） | 不问，修完告诉你 |
| 断了、还能接着干的会话 | 弹选项：「全部找回」「只找回今天的」「都不要了」 | 问（找回会重新开会话、花额度） |
| 断了超过 7 天的会话 | 弹选项：「不再提示」「留着」 | 问 |
| 开着但 3 天没动的会话 | 弹选项：「关掉」「留着」 | 问（关掉会结束它） |
| 在等你回答 / 等你回话的会话 | 不修，告诉你在「待处理」里有几件 | — |

- **弹选项**：Moss 的回复带按钮（T2.3 的 `[[buttons:]]`）；你不在 Moss 页时小莫冒泡「Moss 问你：…」，点按钮就等于回答，不用打字
- **体检简报**：几行字，不是报告。先一句总评，再列修好的、要你定的，比如：
  「体检完了，大体都好。
  · 修好了：补了 2 个会话的名字，钩子重新装好了
  · 要你定：4 个断了的会话，要找回吗？」
  下面是选项按钮；什么都没坏就一句「体检完了，都好好的」
- **每天体检**：每天第一次打开面板时自动体检一次，做的事和手动点「体检」完全一样（不用问的直接修，要问的照样弹选项）
- **设置 ›「Moss」两个开关**：「每天体检」（默认开）；「每天发体检简报」（默认开）。简报关掉时，每天体检照做但不提醒你，简报安静地记在对话里；有要你定的事时仍会提醒

## Scope（YAGNI）

**In**：

- `cc-moss doctor --sessions --json`：各会话的事实（名字是不是自动名、文件夹在不在、断了多久、开着多久没动、在不在等你、tmux 名对不对得上），只给事实、不给结论；判断不了的标 `unknown`
- 代办通道 `cc-moss moss act <动作> … [--because <你的消息 id>] --wait`：Moss 在沙箱里写 `<home>/actions/<id>.json`；守护进程校验后执行，写结果与 `<state>/audit.jsonl`，`--wait` 等结果回来
  - 不用问的动作：`setup-fix`、`sync-name <会话>`、`name <会话> <名字>`（经 `/rename`，会话闲着时）、`forget-gone <会话>`（文件夹已不在的断会话）
  - 要你点头的动作：`restore <会话>`、`forget <会话>`、`end <会话>`；必须带 `--because`，守护进程核对那是一条 `from:"you"`、10 分钟内、回答 Moss 那条带按钮消息的话
  - 一律拒绝对 Moss 自己的动作；会话不存在、状态已变（比如已经被你找回）就跳过并说明
- `moss-doctor` skill：教 Moss 读事实、按上表分档、修完怎么说、怎么出选项
- 内置动作加两个：「体检」「整理会话」（`MossAction` 加两条）
- 每天体检：守护进程在当天第一次看到面板打开时，发给 Moss 和「体检」按钮一模一样的请求；`[moss] daily_checkup = true`、`[moss] daily_brief = true`（简报关掉时 Moss 的简报带 `[[silent]]`，除非有要你定的事）
- 设置 ›「Moss」：「每天体检」「每天发体检简报」两个开关
- 文档：guide 中英「体检」一节；CHANGELOG

**Out**：

- 派发新会话、挑目录：T3.1（复用本任务的代办通道）
- 读会话的对话内容来起名字（隐私承诺，不做）
- 修守护进程或 Moss 自己（它们坏了 Moss 也不在；那是 `cc-moss doctor` 和设置页的事）
