## 行为口径

- source集合的dev/ino/size/mtime_ns/ctime_ns组成epoch，首次观测记fence_ms；任何变化或cache丢失重建fence，不hash或保存认证值。
- epoch首次建立记transcript完整位置水位；成功必须为之后的新完整main assistant、已完成stop_reason、安全模型匹配、timestamp>fence且<=扫描当前时刻、扫描前后source stat一致。
- 旧成功不能重新贴到新epoch。新失败撤销证据；clear/会话或文件换代不继承旧证据。
- 仅Reason::Model且证据有效时不再提示模型待应用；removed永不靠模型响应清除，api_failure仍独立优先。
- LS、banner、批量stale、延后队列recheck语义一致；明确用户单独提交provider-default仍可执行，不因自动标记消失吞掉。
- 只证实当前目标模型已响应，不能说新渠道/凭据已生效；来源不明或stat失败保守保留提示。
- 缓存仍库外，扫描不持主库写锁，模型证据采用向后兼容迁移；不能扩Slot构造或让每行ls重新全扫transcript。
