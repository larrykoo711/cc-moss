## 目标

用真 Claude Code 实测，回答 T1.3 动工前必须知道的三件事，并写下可复现的证据：
1. 会话调用 AskUserQuestion 时，外部程序能否经 hook 把答案交回去，用哪种方式；
2. bypass 会话里 PermissionRequest 会不会触发；
3. 代答 hook 不表态（无输出）或超时后，会话是否照常显示它自己的提示，用户还能在终端里答。

## 实施步骤

1. scratch 下建探针目录，项目级 `.claude/settings.json` 挂两个 command hook：
   - PreToolUse matcher `AskUserQuestion`：把 stdin 原样存档，按环境变量选择回应方式：A 不输出、B `updatedInput` 带答案、C `permissionDecision: "deny"` + 理由「用户已回答：<选项>」、D sleep 超过 `timeout`
   - PermissionRequest：存档 stdin，回 allow
2. 独立 tmux socket（`tmux -L cc-moss-probe`）里在探针目录起 `claude`，分别用普通模式与 `--dangerously-skip-permissions`
3. 让会话「用 AskUserQuestion 问我选 A 还是 B」，四种回应方式各跑一次，记录：hook 收到的 `tool_input`、会话界面（`tmux capture-pane`）、Claude 之后的行为
4. 普通模式下让它执行一条需要权限的命令，看 PermissionRequest 是否触发；bypass 下重复
5. 写 `notes/ask-probe.md`：每问「行 / 不行」+ 证据 + 给 T1.3 的推荐方式与等待时长建议；收尾 `tmux -L cc-moss-probe kill-server`、删 scratch
