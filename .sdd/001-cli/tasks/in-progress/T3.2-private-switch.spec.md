## Scope

**In**（私有仓 + 本机；本仓只记录）
- 迁移脚本（私有仓，可重复执行，逐文件带时间戳备份）：删除四个 `shell-standard: *` 区块与 `source ~/.zsh/t.zsh`，
  整文件推送过的旧 `~/.tmux.conf` 交还给 cc-moss，`t.zsh` 改名退役
- 私有仓只保留：设备清单与多机下发、私有的额外 PATH 区块（个人工具路径）、OpenWrt 精简流程
- 同步流程（macOS / Ubuntu / 本机）：确保目标有 cc-moss（同平台同架构直接复制二进制，否则提示在目标机编译并跳过）→ 迁移
  → 私有区块 → `cc-moss install --yes --with aliases --replace-starship` → `cc-moss doctor`
- 只读验收脚本：starship md5 比对改为 `cc-moss doctor` 必须通过，其余行为探针保留
- 退役：t.zsh、tmuxinator 模板与安装、旧 tmux.conf / starship.toml / 四个区块模板

**Out**：远端设备的实际切换（每台需用户逐台确认，按设备清单执行）；OpenWrt 流程不变
