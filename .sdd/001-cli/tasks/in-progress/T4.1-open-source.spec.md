## 现状（2026-10-16 实读）

- GitHub 仓库私有；简介、6 个 topic、MIT 已设；无 homepage、无社交预览图（显示的是头像）；Issues、Projects 开，Wiki、Discussions 关；三种合并方式全开，合并后不删分支
- 仓内无 `.github/`（无 CI、无 release、无 issue/PR 模板）；无 CONTRIBUTING、SECURITY、CODE_OF_CONDUCT、CHANGELOG
- 历史已于 2026-10-16 用 filter-repo 清理；origin/main 全部提交作者为 GitHub noreply 邮箱
- crate 元数据缺 `readme`、`keywords`、`categories`、`homepage`；moss-core 未声明 `publish = false`
- 没有 tag、没有 Release；`larrykoo711/homebrew-tap` 已存在且公开（另有两个公式，由各自项目的 release 工作流用 `TAP_TOKEN` 自动提交）

## Scope

**In**
- 多路独立评审（只读）：隐私与密钥（工作树 + origin/main 全历史 + 图片元数据）、文档准确性（README 中英与实际 CLI 一致、陌生人首次上手）、
  开源就绪的代码质量（硬编码路径、平台假设、panic、依赖许可证、`cargo package`）、仓库卫生与社区文件与 CI/发布设计
- 按核实后的发现修复，含评审发现的代码稳健性问题（钩子指向已删除的二进制、旧 tmux 的配置报错、大输出卡死、busybox ps 误判、install 卸载、非 zsh 用户等）
- 社区文件：CONTRIBUTING（中英）、SECURITY、CODE_OF_CONDUCT、CHANGELOG、issue 模板（bug / 功能）、PR 模板
- CI：`ci.yml` 在 macOS 与 Ubuntu 跑 `{REPOS}` L3 全部命令（含 tmux、zsh 依赖）
- 发布：`release.yml` 打 `v*` tag 后构建 macOS（arm64、x86_64）与 Linux（x86_64、arm64）二进制 + sha256，发 GitHub Release；homebrew formula 模板
- crate 元数据补齐；README 补「和其他方案的区别」与徽章
- 仓库装修：社交预览图（PNG 1280×640，品牌一致）、简介 / homepage / topics、合并策略（只留 squash、合并后删分支）、Discussions 按用户拍板

**Out（需用户逐项授权后另行执行）**：仓库改为公开；向 `homebrew-tap` 推送公式；打第一个 tag 发 Release；推送 main；上传社交预览图（GitHub 只能网页上传）

## Success criteria

- [x] 私有词表在工作树与 origin/main 全历史零命中；无密钥、无个人邮箱、无本机绝对路径
      verify: `git grep -n -I -i -E -f ~/.config/cc-moss-dev/private-words.txt --untracked -- . ; git log -p origin/main | grep -i -E -f ~/.config/cc-moss-dev/private-words.txt | wc -l` 均为空 / 0；squash 进 main 后对新提交再扫一次（中间提交不公开）
- [x] 评审发现全部核实并处理（修复或写明不修的理由），记 PLAN 日志 REVIEW 行
      verify: `PLAN.md 日志含 T4.1 REVIEW 行`
- [x] CI 工作流在 macOS 与 Ubuntu 上跑 fmt、clippy、test，本地用相同命令全绿
      verify: `actionlint .github/workflows/*.yml && cargo fmt --all --check && cargo clippy --all-targets -- -D warnings && cargo test --all`
- [x] Linux 发布目标能在干净容器里构建并跑通 `--version`、`doctor`（借空闲机 Docker）
      verify: `scripts/clean-room.sh 通过`
- [x] `cargo package -p cc-moss --list` 不含档案、测试夹具以外的无关文件；moss-core 不发布到 crates.io 时声明 `publish = false`
      verify: `cargo package -p cc-moss --list --allow-dirty`
- [x] 社区文件与模板齐全，README 中英同步、链接与图片全部可达
      verify: `ls CONTRIBUTING.md SECURITY.md CODE_OF_CONDUCT.md CHANGELOG.md .github/ISSUE_TEMPLATE .github/pull_request_template.md && lychee --offline README.md README.zh-CN.md`
- [x] 仓库设置与装修完成（topics、合并策略、社交预览图文件就绪）
      verify: `gh repo view --json repositoryTopics,squashMergeAllowed,mergeCommitAllowed,deleteBranchOnMerge`
