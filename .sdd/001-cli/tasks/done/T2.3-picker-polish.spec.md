## 目标

一眼看清每个会话在干什么：正在工作的（有动画）和在等你输入的分组显示，每行带上你最后一句话的开头；
页头有 MOSS 的眼睛和当前目录；搜索时匹配的字符高亮；提示行随选中项给出当下能做的事。

## Scope

**In**
- 登记表：`busy`（UserPromptSubmit 置 1，Stop / SessionEnd / SessionStart 置 0）、`last_prompt`（UserPromptSubmit 的 `prompt`
  取首行、去掉首尾空白、截到 200 字符）。旧库由 `ensure_columns` 补列。`ls --json` 增加 `busy`、`last_prompt` 两个字段（向后兼容）
- 选择器分组：Interrupted / Working / Waiting / Other tmux；**去掉 Folders 组**（一个目录可有多个会话，按目录进入有歧义）；
  新建会话的目录 = 运行 `t` 时的当前目录；Working 的状态符每 120ms 轮转动画
- **每个会话两行**：第一行 状态符 · 名字 · 备注 · 右对齐时间；第二行 所在目录 · 最后一句话预览（灰）
- **搜索框**：页头下方带圆角边框的输入框，真实光标，右上角显示匹配数（`3 of 12`）
- **分区**：页头、搜索框、各分组（组标题带横线）、底部提示（上方一条分隔线）界限分明
- 页头三行：MOSS 眼睛小标 + `cc-moss` 与版本 + 概要（`2 working · 3 waiting · 1 interrupted`）+ 当前目录

- 搜索匹配字符高亮（橙色加粗），用 nucleo 的匹配位置
- 提示行按选中项变化：`enter attach` / `enter restore` / `enter start "<名字>" in <目录>`

**Out**：配色主题、鼠标点击（YAGNI）
