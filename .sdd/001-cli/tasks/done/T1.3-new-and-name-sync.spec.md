## 目标

`cc-moss new em-a` 建出一个 tmux 会话 `<主机前缀>_em-a`，里面跑着名为 `em-a` 的 Claude Code；在会话里
`/rename em-b` 之后，发出下一条消息时，tmux 会话名自动变成 `<主机前缀>_em-b`。同时，每个会话的启动参数
（如 `--dangerously-skip-permissions`）被记下来，供 T1.4 恢复时原样带回。

## Scope（YAGNI）

**In**
- `moss-core::naming`：主机前缀（macOS 用 `scutil --get LocalHostName`，其他平台或失败时用 `hostname -s`）、
  `sanitize`、`tmux_session_name(prefix, name)`、在已有名字集合里取不重名的名字（`-2`、`-3`…）
- `moss-core::config`：`$XDG_CONFIG_HOME/cc-moss/config.toml`（默认 `~/.config/cc-moss/config.toml`），
  字段 `claude.default_args: [String]`、`naming.host_prefix: bool`（默认 true）、`tmux.socket: Option<String>`；
  文件不存在时全用默认值
- `moss-core::tmux` 扩展：命令执行经 `Runner` trait 注入；`new_session`、`rename_session`、`session_names`、
  `current_session_name(pane)`、`attach_or_switch`；全部支持指定 socket（`-S`）
- `moss-core::launch_args`：从 `ps -o args= -p <pid>` 的输出里按白名单提取参数
- `cc-moss new [name] [-C dir] [--detach] [-- claude 参数…]`：名字缺省为工作目录的 basename；
  生成 UUID，在 tmux 里执行 `claude -n <name> --session-id <uuid> <default_args> <参数>`；随后 attach
  （已在 tmux 里就 `switch-client`；`--detach` 不 attach）
- `new` 建出的 tmux 会话只有一个窗口，直接运行 claude；claude 退出即会话结束（R9）
- hook 扩展：SessionStart 记录启动参数；SessionStart 与 UserPromptSubmit 时，如果槽位在 tmux 里且是该 tmux 会话的
  「主槽位」（同一 tmux 会话里最早登记且仍在运行的槽位），而当前 tmux 会话名与期望名不同，就 `rename-session`；
  非主槽位不做任何 tmux 操作（R9 下这是用户手动造成的少见情况）
- 不在 tmux 里时，SessionStart 在 stdout 输出 `{"systemMessage": "…"}` 提醒用户本会话不受终端崩溃保护
  （这是 stdout 唯一允许的输出，必须是合法 JSON）

**Out**
- `new -m <备注>`：此时槽位尚未登记，预登记会在 claude 启动失败时留下永远 running 的幽灵槽位；备注统一走 T1.4 的 `note`
- `cc-moss rename`：只能改 tmux 和登记表、改不了 Claude 内部的名字，价值低，`/rename` 已覆盖 → 不做
- 恢复 → T1.4
- 多窗口支持（改窗口名、窗口级定位）：R9 定一会话一窗口

## 契约

- 启动参数白名单（带值）：`--permission-mode` `--model` `--effort` `--add-dir`（可多次）`--agent`；
  （布尔）`--dangerously-skip-permissions`。其余一律丢弃，包括 `-p` `--resume` `-n` `--name` `--session-id`
  `--fork-session` 和位置参数。值看起来像凭据（含 `sk-`、`key`、`token`、`secret`，不区分大小写）的连同参数名一起丢弃
- `launch_args` 列存 JSON 字符串数组，`ls --json` 不输出（schema 1 不变）

## 风险与回退

- **改名打到用户的其他 tmux 会话**：只改登记表里记录的 `tmux_session_id`（`$N`，不按名字定位）；该 id 已不存在就跳过
- **ps 输出里参数含空格会被拆错**：已知限制，只影响带空格的 `--add-dir` 路径；记进 deliberately_skipped
- 回退：config 里关掉前缀不影响同步；彻底回退 = `setup --uninstall`
