## 目标

Claude Code 每发生一次会话事件，`cc-moss hook <event>` 都把它记进本机登记表；之后任何时候执行
`cc-moss ls`，都能看到每个会话的名字、状态（运行中 / 已关闭 / 意外中断）、工作目录、所在 tmux 和
最后活动时间。重启之后，`ls` 列出的「意外中断」就是需要恢复的会话，不需要再翻会话记录。

## Scope（YAGNI）

**In**
- Cargo workspace：`crates/moss-core`（库）+ `crates/cc-moss`（二进制），MSRV 1.80
- 登记表：SQLite（WAL、busy_timeout 1s；首次打开时切 WAL 带退避重试），schema 版本表 + 迁移函数；存储目录解析
- 槽位模型与状态机（DESIGN §3 §4）
- `Agent` trait + `ClaudeAgent`：解析四种钩子输入，归一成内部事件
- `cc-moss hook <session-start|user-prompt-submit|stop|session-end>`：读 stdin，更新登记表；永远 exit 0，
  stdout 不输出，错误写 `hook.log`；只处理交互式会话（F10）；外部命令（`ps`、`tmux`）一律 500ms 超时
- 记录 `TMUX`（socket 路径）与 `TMUX_PANE`，以及当时的 tmux 会话 id、会话名（用一次 `tmux display-message`
  取；失败就留空，不影响写入）
- `cc-moss ls [--all] [--json]`，含进程存活与 pid 复用判定

**Out**
- tmux 改名、`new`、启动参数采集 → T1.3（本任务只记录 tmux 位置，不改 tmux）
- 写 `~/.claude/settings.json` → T1.2（本任务的钩子靠测试和手工 `--settings` 驱动）
- `restore`、`note`、`close` → T1.4
- 备注字段的写入入口 → T1.4（schema 本任务就建好，避免后续迁移）

## 行为口径

| 项 | 口径 | 用户确认 |
|----|------|---------|
| 关闭的判定 | 只有 `prompt_input_exit`、`logout`、`resume`（会话内切走，F11）算关闭；其余 reason 和「无 SessionEnd 且进程已不在」都算意外中断 | 2026-10-15 G1；`resume` 于评审轮补入 |
| 一个进程的槽位数 | 同一进程（pid + 启动时间）只保留一个 running 槽位；切到别的会话时旧槽位记为 closed（`switched`） | 2026-10-15 评审轮（F11） |
| 非交互会话 | `claude -p`、SDK 会话不登记；以 `CLAUDE_CODE_SESSION_ATTENDED` 判断 | 2026-10-15 评审轮（F10、R3） |
| 进程身份 | pid 且启动时间都已知且相等才算同一进程；任一未知时不关闭、不接管 | 2026-10-15 评审第 2 轮（R2） |
| `ls` 默认范围 | 运行中 + 意外中断；`--all` 再加已关闭 | 2026-10-15（DESIGN §7） |
| `ls` 排序 | 意外中断在前，其后运行中；同组按最后活动时间倒序 | 自决（默认值：最需要处理的排最前） |
| 时间显示 | 相对时间（`3m`、`2h`、`1d`） | 自决 |

## 契约

- **钩子命令行**：`cc-moss hook <event>`，event ∈ `session-start` `user-prompt-submit` `stop` `session-end`。
  T1.2 写进 settings.json 的就是这四个字面量（protocol literal，T1.2 spec 引用本节）
- **`ls --json` schema 1**（Stage 2 消费，向后兼容）：

```json
{ "schema": 1,
  "slots": [ { "slot_id": "01J…", "agent": "claude", "name": "em-a", "status": "interrupted",
               "session_id": "uuid", "session_ids": ["uuid"], "cwd": "/abs",
               "tmux": { "socket": "/tmp/tmux-501/default", "session_id": "$3", "session_name": "host_em-a", "pane_id": "%7" },
               "pid": 12345, "end_reason": "other",
               "notes": { "goal": null, "state": null, "note": null },
               "created_at": "RFC3339", "last_active_at": "RFC3339", "ended_at": null } ] }
```

  `tmux` 不在 tmux 里时为 `null`。字段只增不改名
- **存储目录**：`$CC_MOSS_STATE_DIR` > `$XDG_STATE_HOME/cc-moss` > `~/.local/state/cc-moss`；文件 `registry.db`、`hook.log`

## 风险与回退

- **钩子拖慢或卡住 Claude**：fail-open。任何错误都吞掉并记日志；SQLite 忙等超过 200ms 就放弃本次写入
- **登记表损坏**：hook 打开失败时记日志并 exit 0；`ls` 报错并提示删除 `registry.db` 重建（只丢登记，不影响 Claude 本身）
- 回退：从 settings.json 删掉钩子即可完全停用（T1.2 提供 `--uninstall`）
