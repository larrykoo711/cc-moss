## 现状（2026-10-16 实读）

- 面向用户的文字约 130 处，全部硬编码英文：选择器（`pick/ui.rs`、`pick/app.rs`、`pick/mod.rs`）、
  命令输出与报错（`cmd/*.rs`）、`--help`（clap derive 文档注释）、钩子发给 Claude Code 的 `systemMessage`
- 本机实测：`LANG=en_US.UTF-8`（终端默认写入），而系统语言是 `zh-Hans`（`defaults read -g AppleLanguages`），
  只看 `LANG` 会把中文用户判成英文

## Scope

**In**
- 语言判定（首个命中即用）：`CC_MOSS_LANG` → 配置 `[ui] language`（`auto`/`en`/`zh`）→ `LC_ALL` → `LC_MESSAGES`
  → macOS 系统首选语言 → `LANG` → 英文；`zh*` 判为中文，其余为英文；只在需要输出文字时才判定（钩子热路径不受影响）
- 两种语言的文案在同一处成对书写（漏写一种无法编译）
- 覆盖：选择器全部文字（页头计数、搜索占位、状态、卡片、菜单、确认框、提示行、相对时间、操作反馈）、
  所有命令的输出与面向用户的报错、`--help` 的命令说明与参数说明、钩子的 `systemMessage`
- 文案风格：简短、口语、友好，少量不打扰的小幽默（例如恢复时「全员健在」）；不用 emoji
- README 两种语言的配置示例加上 `[ui] language`

**Out**
- `ls --json`、钩子日志、底层技术报错（tmux/文件系统原始错误）保持英文，便于搜索与排障
- clap 自带的 `Usage:`/`Options:` 标题（clap 无内建国际化；仅替换为中文模板，不改其行为）——见验收第 5 条
