## 目标

敲 `t` 打开一个全屏选择器：上方是搜索框，下方是列表，三个标签页 Sessions / Folders / Interrupted。
模糊搜索、回车进入：在会话上进入它，在目录上为该目录开一个 Claude 会话，在中断项上恢复并进入。
列表里直接看到 Claude 会话名、状态、备注。旧 `t.zsh` 盘点出的 4 处缺陷不再出现。

## Scope（YAGNI）

**In**
- `crates/cc-moss/src/pick/`：ratatui + crossterm 的界面；nucleo-matcher 模糊匹配；逻辑（`App` 状态与按键 → 动作）
  与终端绘制分离，逻辑可在无终端时测试
- 三个标签页：
  - **Sessions**：tmux 会话列表（配置的 socket），能对应到 Claude 槽位的显示 Claude 名、状态、备注；
    首行 `+ new session`（以当前目录名新建，同名规则走 T1.5）
  - **Folders**：`zoxide query -l` 的目录（没装 zoxide 时该标签页显示一句说明）；回车 = `cc-moss new -C <dir>`
  - **Interrupted**：有效状态为中断的会话；回车 = 恢复（T1.4 的 `Launcher`）并进入
- 按键（不占用任何可打印字符，搜索框能输入所有字母数字）：
  `Tab` / `Shift-Tab` 切标签页 · `↑↓` / `Ctrl-P` `Ctrl-N` 移动 · `Enter` 执行 · `Ctrl-X` 删除（结束 tmux 会话；
  对 Claude 会话同时标记为已关闭，不再进入恢复列表）· `Ctrl-R` 刷新当前标签页 · `Esc` / `Ctrl-C` 退出
- 删除二次确认：选中行底部出现「Kill <name>? y/N」，只有 `y` 才执行
- 回车后先退出全屏、恢复终端，再执行 attach / switch-client（在 tmux 内切换，在外面附着）
- 状态机补一条：已被用户关闭的槽位，之后到达的 `SessionEnd(other)` 不再改回中断（`Ctrl-X` 杀会话时 claude 会收到 SIGHUP）
- macOS 隐私权限：建会话前（`new`、`restore`、选择器里的新建与恢复）用 `tmux run-shell` 探测 server 能否读该目录；
  不能时报错并提示重启 tmux server（不自动 kill-server，那会杀掉所有会话）
- zsh 集成：`cc-moss setup` 额外维护 `~/.zshrc`（`$ZDOTDIR` 优先）里的受管区块，定义 `t` 指向 `cc-moss pick`；
  区块插在 `starship init` 之前（坑 #8）、整块替换、`--uninstall` 移除；同样先 diff 再确认、写前备份
- `moss-core::managed_block`：区块的插入、替换、移除（纯函数），T3.1 复用

**Out**
- Windows 标签页、tmuxinator 模板：R9
- 多选、批量操作：先看使用反馈
- 自定义配色 / 键位配置：YAGNI

- 回退：删掉区块即回到旧 `t`
