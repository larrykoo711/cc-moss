## Scope

**In**
- `cc-moss install [--with aliases] [--skip tmux|starship|shell] [--dry-run] [--yes]`
  - tmux：写 `~/.config/cc-moss/tmux.conf`（cc-moss 所有）；`~/.tmux.conf` 顶部受管区块只含一行 `source-file`；
    剪贴板按平台选择；新增 `prefix + t` 弹出选择器
  - starship：`$STARSHIP_CONFIG` 或 `~/.config/starship.toml` 不存在则写入；已存在且不同则展示 diff、默认不覆盖
  - shell：`.zshrc` 的 `cc-moss: prompt`（starship init；已有手写 init 时跳过）与 `cc-moss: ssh-tty-restore`，
    `.zshenv` 的 `cc-moss: path`（brew、`~/.local/bin`、`~/.cargo/bin`）
  - aliases（可选）：`cc-moss: aliases`，兼容 Debian 的 `batcat`/`fdfind`
  - 先汇总全部 diff、一次确认、逐文件留时间戳备份后原子写入（复用 setup 的实现）
  - 依赖：检测平台（macOS / Debian 系 / 其他），列出缺失项与安装命令，确认后执行；其他平台只打印
- `cc-moss doctor`：逐项 ✓/!/✗ 并给修复命令；✗ 时退出码非零。覆盖：钩子、`t`、tmux 及其配置、starship 及配置与
  init 顺序（坑 #8）、ssh 复位区块（坑 #13）、`.zshenv` PATH（坑 #12）、区块外同名 alias（坑 #10）、claude、依赖
- 全部文字中英双语（T2.5 的 `tr!`）

**Out**
- 迁移私有仓 `shell-standard: *` 区块（T3.2 负责）；tmuxinator / sesh / fzf（R9 与原生选择器已替代）；OpenWrt
- 字体检测（doctor 只提示 starship 需要 Nerd Font）
