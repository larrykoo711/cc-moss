## 目标

`t` 打开后像 `claude agents`：顶部品牌与概要，中间一个按状态分组的列表（待恢复 → 会话 → 目录），
选中行整行底色，底部两条细线夹着输入框，最下一行灰色提示，`?` 展开快捷键面板。

## 设计依据（2026-10-16 实测 `claude agents`，Claude Code 2.1.300）

| 元素 | agents 的做法 | 本任务 |
|------|---------------|--------|
| 页头 | 品牌标（橙 `#D77757`）+ 粗体名称 + 灰色版本；灰色概要 `1 awaiting input · 0 working · 0 completed` | `◉`（MOSS 的红色眼睛）+ `cc-moss` 粗体 + 灰版本；灰色概要 `tmux · 9 running · 1 interrupted · 13 folders` |
| 主体 | 按状态分组，组名粗体；行 = 彩色状态符 + 名称 + 灰色说明 + 右对齐时间 | 组：Interrupted / Sessions / Folders；行 = 状态符 + 名称 + 备注 + 灰色目录 + 右对齐时间 |
| 选中 | 整行深灰底 `#373737` + 粗体白字 | 同 |
| 输入 | 底部两条细线之间 `❯ describe a task…`（灰色占位） | `❯ search, or type a name to start a new session` |
| 提示 | 一行灰字，`·` 分隔；`?` 展开三列快捷键 | 同 |
| 灰色 | `#999999` | 同 |

## Scope

**In**
- 去掉标签页，改为分组单列表；空组不显示；Tab / Shift-Tab 在组之间跳
- Folders 组：无搜索时只显示前 5 个加「… N more」；搜索时全部参与匹配
- 搜索同时过滤所有组；组内按得分排序，组顺序不变
- 新建：搜索词不等于任何会话名时，列表顶部出现 `+ new "<搜索词>"`；搜索为空时顶部是 `+ new session`
- tmux 会话名去掉本机前缀显示（`host-a_billing` → `billing`）；非 Claude 的 tmux 会话标灰色 `tmux`
- 目录列：`~` 缩写，过长时保留首尾（`~/…/acme`）；时间右对齐；宽字符（中文备注）按显示宽度对齐
- `?`：搜索框为空时切换快捷键面板，非空时照常作为搜索字符
- 删除确认、消息沿用 T2.1 的行为，换成新样式

**Out**：配色可配置、Unicode 不可用终端的降级（YAGNI）
